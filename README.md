# Desserts Shop 🍰

¡Hola! Este es un proyecto de lista de productos con carrito de compras interactivo, desarrollado como parte de los retos de Frontend Mentor.

## 🚀 Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, CSS Grid y diseño responsivo)
- JavaScript Vanilla (Manipulación del DOM y manejo del estado)

## 🛠️ Características del proyecto

- Agregar postres al carrito y controlar sus cantidades individuales.
- Renderizado dinámico de los elementos agregados.
- Modal con el resumen detallado de la orden confirmada.
- Reinicio completo de la aplicación para una nueva orden.
